Bulk edit gains polish and its mobile sheet. The desktop bar's fields have visible labels, **Delete** says how many it would hit, the rating options read "**5 stars**", a change that would land says it reverts in one undo, and **Auto-Tag** suggests tags for the selection with your LLM — only when a provider is configured, landed in the Add-tags field so it is reviewed before Apply, which stays the only write. On windows narrower than `lg`, the selection bar's **Bulk Edit** opens a full-page sheet: the selected items' preview, move-to-folder, add/remove tags, and a Danger Zone with the count, with **Cancel** and **Apply Changes** pinned to the bottom. Applying is still one write and one undo.
