The weekly digest is a workspace view. On windows from `lg` up, **Weekly Digest** in the sidebar (or the navigation drawer) opens the weekly-digest mockup's full page beside the navigation rail instead of a modal over the list: the week's range under the title with **Show never opened** and **Triage untagged** in the header, the **Arrived this week / Settled & never opened / Needs tags** figures as a summary strip, and the week's additions as named topic clusters of bookmark rows — favicon roundel, title, URL — that open like everywhere else. The centered desktop modal retires; below `lg` the digest is still the full-page sheet with the Needs Review queue, and no write path changed — the two header actions remain the never-opened filter and the organizer's tag review.
