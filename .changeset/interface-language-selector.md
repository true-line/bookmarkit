The Options dialog's Appearance section gains **Interface Language**. "System default" follows the browser's own language; English is the locale the catalogue ships today, and a locale appears in the select as soon as its message file lands. The choice persists to the browser and applies immediately — copy, number and date formats, and the document's `dir`, which mirrors the whole interface for right-to-left locales (the selector, the sidebar and dialogs are built on logical properties; the folder tree's indentation follows when #291's utility sweep lands).
