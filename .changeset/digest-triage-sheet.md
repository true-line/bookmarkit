The weekly digest has its mobile sheet. On windows narrower than `lg`, opening the digest leaves the centered modal for a full-page composition: the week's **Saved / Unopened / Untagged** counts as a summary card, an **Auto-Tag** strip that hands the untagged set to the organizer exactly as the modal's triage action does, and a **Needs Review** queue that reads the never-opened and untagged sections as one deduplicated list, newest save first — every card with **Open** and a **Tag & File** action that opens the ordinary edit form, all controls at the mockup's 44px targets. No new write path: triage reviews through the same diff, Tag & File saves through the form.
